# Task records

Tasks opens a paged history of retained B3R runs, including ordinary conversations and governed tasks. Finished, failed, interrupted and cancelled runs remain available, including those in archived conversations. Deleted conversations and tasks outside B3R are excluded. Select a run to inspect its goal, attempts, recorded revision, process entries, results and errors. The detail URL can be bookmarked or reloaded. Open its conversation to stop active work, retry, or read older process entries.

Execution shows only provider-confirmed model identity; the requested model is separate. Missing identities and usage remain unavailable. Token counts use provider input/output accounting, with partial coverage labelled; cache and reasoning subsets are not added twice. Legacy incremental reports without a retained ledger are unknown. No token estimates are invented.

Elapsed time uses recorded start/end timestamps. A rough remaining-time estimate appears only with at least five completed runs on the current page using the same confirmed provider/model. It uses their median duration and is not a promise: workloads can differ. Waiting, queued, missing-model and insufficient-history cases explain why no estimate is available. Refreshing or reconnecting reloads the persisted evidence.

## Create and manage governed tasks

Below the run history, **Create & manage governed tasks** keeps the existing task inbox, drafts and governance controls.

Use **Tasks** to search task titles or IDs and filter by project, assignee or recorded attention
facts. Inbox filters are separate from the project and provider used to create a task. Historical
projects and unavailable assignees remain selectable. **Reset inbox filters** returns to all tasks.

Attention labels can overlap. The command ledger, provider outcome and owner acceptance are
separate evidence; a completed ledger entry does not establish successful work. Acceptance of an
older revision does not accept the current revision. A paused revision describes its contract
phase, not confirmed provider termination. Stale or missing facts remain visibly unknown.

Select a task to open its existing review, instructions, budget, routing, result and Stop controls.
**Back to task inbox** keeps your filters. Live updates do not switch your selected task, even if it
no longer matches a filter. Missing or ambiguous task identities open no controls. Selecting or
filtering starts no work. Switching tasks retires executable reviews; retained text drafts still
need fresh review, and original recovery identities keep their existing reconciliation flow.
